# CadastroUsuario

API para gerenciamento de usuários (CRUD), desenvolvida em .NET.

## 🚀 Funcionalidades
- Cadastro de usuário
- Consulta de usuários
- Atualização
- Remoção (Ativar/Desativar)

## 🏗️ Estrutura
- **API**: Controllers / endpoints
- **Application**: Regras de negócio
- **Core (Domain)**: Entidades e contratos
- **Infrastructure**: Acesso a dados

## 🛠️ Tecnologias
- .NET / C#
- ASP.NET Web API
- SQL Server
